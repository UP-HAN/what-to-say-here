# 제품 기획서 (PRD) v0.1
## 가칭: 「여기서 뭐라고 해요?」 — 장소 기반 왕초보 영어 회화 앱

작성일: 2026-08-01 | 상태: 초안 (검토 필요)

---

## 1. 한 줄 정의

> 구글 지도에서 **지금 갈 장소**를 검색하면, **그곳에서 실제로 쓸 문장 5개**를 왕초보도 바로 읽을 수 있는 형태로 꺼내주는 앱.

---

## 2. 문제 정의

기존 영어 회화 앱의 구조적 한계:

| 문제 | 설명 |
|---|---|
| **커리큘럼이 내 상황과 무관** | "Unit 3. 취미 말하기"를 배워도, 정작 공항 수하물 창구에서 입이 안 떨어짐 |
| **왕초보에게 진입장벽이 높음** | 발음기호(IPA), 문법 설명, 긴 대화문 → 첫 화면에서 포기 |
| **"공부"가 목적이 되어버림** | 실제로 말해야 하는 순간에 앱을 켜지 않음. 학습 앱은 집에서, 위기는 현장에서 발생 |
| **검색이 어려움** | "약국에서 소화제 살 때 영어"를 찾으려면 유튜브를 10분 뒤져야 함 |

**핵심 통찰:** 왕초보에게 필요한 건 *영어 실력*이 아니라 *지금 이 3분을 넘길 문장 한 줄*이다.
학습은 그 성공 경험 이후에 따라온다.

## 3. 타깃 사용자

### 주 페르소나 A — "해외여행 3주 전, 김OO(45)"
- 영어 = 알파벳은 읽지만 문장은 못 만듦. 토익 응시 경험 없음
- 다음 달 가족 여행. "호텔 체크인만 어떻게든 넘기고 싶다"
- 니즈: 완벽한 문장 X → **틀려도 통하는 문장** O
- 사용 순간: ① 여행 전날 밤 예습 ② 현장에서 급하게

### 주 페르소나 B — "외국인 손님 응대해야 하는 자영업자"
- 카페/게스트하우스 운영. 갑자기 외국인이 들어옴
- 니즈: 내 가게에서 반복되는 5문장

### 부 페르소나 C — 초등 고학년 / 중학생 (확장 가능성)
- 교실에서 "역할극 상황 카드"로 활용 가능
- ※ MVP 범위에서는 제외. 단, 콘텐츠 톤은 아동이 봐도 무리 없게 설계

## 4. 차별점 (이게 없으면 이 앱은 존재 이유가 없음)

1. **입력이 '주제'가 아니라 '장소'다.**
   - 기존: "쇼핑 표현 배우기" → 추상적
   - 우리: "스타벅스 강남역점" 검색 → 그 장소에 맞는 문장
2. **장소 종류를 상황으로 자동 번역한다.**
   - 카페 → 주문 / 와이파이 / 화장실 / 포장
   - 약국 → 증상 말하기 / 복용법 묻기
   - 공항 → 체크인 / 짐 부치기 / 게이트 찾기
3. **현장에서 쓰는 앱이다.** 공부용 UI가 아니라 **꺼내 보여주는 UI**.
4. **가입도 로그인도 없다.** 열면 바로 쓴다. 왕초보에게 회원가입은 그 자체로 이탈 지점.

## 5. 핵심 사용자 흐름 (Core Flow)

```
[1] 앱 실행
     ↓
[2] 장소 검색  ─── (또는) 현재 위치 기반 "지금 여기" 버튼
     예: "Narita Airport" / "CVS Pharmacy" / "우리 동네 카페"
     ↓
[3] 상황 선택 카드 (해당 장소에서 자주 벌어지는 일 3~5개)
     예) 카페 → ☕주문하기 / 📶와이파이 / 🚻화장실 / 🥡포장
     ↓
[4] 문장 카드 5장 제시
     - 영어 문장 (크게)
     - 한글 뜻
     - 한글 소리 표기 (예: "캔 아이 겟 어 커피?")
     - 🔊 원어민 발음 듣기
     ↓
[5] 액션
     - [🗣 따라 말하기]  → 발음 체크 (P1)
     - [📱 상대방에게 보여주기] → 화면 전체에 문장 크게 (오프라인 동작)
     - [⭐ 내 카드에 저장]
```

**설계 원칙:** 3번의 터치 안에 "말할 문장"에 도달해야 한다.

## 7. 콘텐츠 설계 원칙 ★가장 중요★

이 앱의 품질 = 문장의 품질. 생성 규칙을 못 박아 둡니다.

1. **문장 길이 8단어 이내.** 길면 왕초보는 안 읽음
2. **문법적 완벽함 < 통하는가.** "Water, please." 허용
3. **발음기호(IPA) 절대 사용 금지.** 한글 소리 표기만
4. **한 화면에 문장 5개 초과 금지**
5. **격식 낮음 → 높음 순서로 배치하지 않는다.** 가장 자주 쓰는 것을 1번에
6. **문화 주석 1줄.** 예: "미국 카페는 이름을 물어봐요"
7. **아동이 봐도 무리 없는 어휘/상황만** (부 페르소나 대비)

### 문장 카드 데이터 구조 (예시)

```json
{
  "place_type": "cafe",
  "situation": "주문하기",
  "cards": [
    {
      "en": "Can I get an iced americano?",
      "ko": "아이스 아메리카노 하나 주세요.",
      "sound": "캔 아이 겟 언 아이스드 아메리카노?",
      "note": "'get' 대신 'have'도 똑같이 통해요.",
      "reply_expected": "For here or to go? (매장? 포장?)"
    }
  ]
}
```

## 8. 기술 구조 — 완전 정적 (서버 없음) ★확정

### 결정의 근거

카드는 **장소 이름**이 아니라 **장소 종류**로 결정된다.
"하와이 힐튼호텔"이든 "방콕 메리어트"든 체크인 영어는 같다.
→ 세상의 모든 장소 데이터가 필요한 게 아니라 **종류 30개**만 있으면 된다.

```
장소 종류 30 × 상황 4 × 카드 4장 = 480장 ≈ 250KB
```

이걸 앱에 통째로 넣으면 서버·로그인·API 키가 전부 사라진다.

### 구조

```
사용자 폰
 ├ 앱 (HTML/JS/CSS)     ← 정적 호스팅 (GitHub Pages 등, 무료)
 ├ 카드 데이터 250KB     ← 앱에 동봉
 └ 담아둔 카드           ← 폰 로컬 저장

서버 없음 · 로그인 없음 · 회원가입 없음 · 유지비 0원
```

### 검색 처리

구글 Places API를 쓰지 않는다. 입력 문자열에서 **종류 키워드만 매칭**한다.

```
"하와이 힐튼호텔" → 호텔     "나리타 공항"  → 공항
"CVS 약국"       → 약국     "스타벅스"     → 카페 (브랜드 사전)
```

- 브랜드 사전(스타벅스→카페, CVS→약국 등) 별도 관리
- 매칭 실패 시 종류 목록에서 직접 선택하도록 유도

### 오프라인

PWA로 배포. 홈 화면에 추가하면 **비행기 모드에서도 전체 기능 동작.**
담아둔 카드는 폰 로컬 저장소에 JSON으로 보관 (100장 ≈ 50KB).

### 포기한 것

**목록에 없는 장소는 지원하지 않는다.** ("네팔 트레킹 허가사무소" ✕)
여행자 방문지의 약 90%가 30종류 안에 들어간다는 판단. 롱테일을 버리고
서버·로그인·유지비를 전부 버리는 거래.

## 10. 리스크

| 리스크 | 대응 |
|---|---|
| **480장 제작 부담 ★최대 리스크** | 세트당 10분 × 120세트 ≈ 20시간. 이게 이 프로젝트의 진짜 일이다. 상위 10종류 먼저 만들어 출시하고 나머지는 이후 채움 |
| **없는 장소 검색 시 이탈** | 매칭 실패 화면을 잘 설계할 것. "비슷한 곳 고르기" 목록 제시 |
| **LLM 문장 품질 편차** | 사전 생성분은 사람이 검수. 프롬프트에 §7 원칙 하드코딩 |
| **한글 소리 표기의 한계** | "통하는 수준"이 목표임을 앱 내에서 명시. 완벽 발음 아님 |
| **해외 데이터 없음** | 오프라인 저장(F7)을 P0에 넣은 이유 |
| **차별점이 쉽게 복제됨** | 콘텐츠 품질과 왕초보 UX 디테일이 해자. 기능 자체는 방어 불가 |

### 듣기 포함에 따른 구조 변경 ★

문장 카드가 **왕복 구조**가 됩니다. 이건 단순 기능 추가가 아니라 제품의 뼈대 변경입니다.

```
[내가 할 말]  Can I check in here?
      ↓
[상대가 할 말]  Passport, please.        ← 신규 P0
                "패스포트, 플리즈" / 여권 주세요
      ↓
[그럼 나는]   Here you go.               ← 신규 P0
```

- 한 장의 카드 = 대화 한 턴이 아니라 **한 상황의 왕복 3턴**
- 왕초보에게 "상대가 이렇게 말하면 당황하지 마세요"는 문장 5개보다 값어치가 큼
- 상대 대사에도 **한글 소리 표기 필수** (귀로 매칭하기 위함)
