## 이미 끝낸 것 (코드) ✅

`js/app.js`에 **상황 검색 + 공통 상황** 지원을 넣음 (데이터가 없어도 안전하게 동작하도록 가드 있음):

- `lookup()`: 검색 순서 = ① 명소 이름 → ② 장소 종류 이름 → ③ **공통 상황**(`DB.common_situations`) → ④ **종류 안의 상황**(situation의 `keywords` 또는 `label`)
- `search()`: 상황이 지정되면(`r.sit`) 바로 그 상황으로 점프
- `render()`/`currentCards()`/`stamp()`: `kind==='commonsit'`(공통 상황)이면 **상황 고르기 없이 카드를 바로** 보여줌. 헤더에 "어디서나 쓰는 말" 표시
- `sw.js` 캐시 `phrase-v18`

→ **app.js 코드는 완료.** 이제 `data/cards.json`에 데이터만 채우면 검색이 작동한다.

## 데이터 스키마 (반드시 이대로)

카드 1장 = 다국어 구조(지금은 `en`만 채움, `ja`는 나중):

```json
{
  "intent": "화장실이 어디예요?",
  "say": { "en": { "t": "Where's the restroom?", "s": "웨어즈 더 레스트룸?" } },
  "reply": { "en": [ { "t": "Down the hall.", "s": "다운 더 홀", "ko": "복도 끝에 있어요." } ] },
  "note": "미국은 restroom/bathroom을 써요. toilet은 잘 안 써요.",
  "volatile": false
}
```

**(가) 공통 상황** — 새 최상위 배열 `common_situations` (장소와 무관, 검색되면 카드 바로 표시):

```json
"common_situations": [
  {
    "key": "restroom",
    "label": "화장실",
    "emoji": "🚻",
    "keywords": ["화장실","화장실어디","restroom","toilet","wc","bathroom","변소"],
    "cards": [ /* 위 카드 구조 4~5장 */ ]
  }
]
```

**(나) 새 장소 종류** — 기존 `types`와 똑같은 모양. 단, **각 상황에 `keywords` 추가**(상황 검색용):

```json
"편의점": 아님. key는 영문 스네이크. 예:
"convenience": {
  "label": "편의점",
  "keywords": ["편의점","씨유","GS25","세븐일레븐","convenience","마트"],
  "situations": [
    { "emoji":"🧴","label":"물건 찾기","keywords":["물건","어디있어요"], "cards":[ /* 4장 */ ] }
  ]
}
```

**(다) 기존 상황에도 `keywords`를 달아** 상황 검색이 되게 (예: 공항 "체크인하기"에 `["체크인","탑승수속"]`).
