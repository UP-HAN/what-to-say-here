## 구조

- `clothing` / 옷가게 — 이거 찾아요 · 사이즈 묻기 · 입어보기 · 사고 바꾸기
- `salon` / 미용실 — 들어가기 · 자르기 전 · 자르는 중 · 자르고 나서

신형식(다국어 구조) `intent` / `say.en{t,s}` / `reply.en[{t,s,ko}]` / `note` / `volatile`. 지금은 en만.

## 감수 이력 (content → reviewer 3라운드 + 코디네이터 1라운드)

**1차 반려** — 안 통하는 문장 5건, 연음·유성음 표기, 규정 단정 4곳, 상황 순서
**2차 반려** — `Or skip it.`(조각 문장), `Card or cash?`(어순은 `Cash or card?`), `Come again.`(되묻는 말로 오해), `Bags cost extra.`(미국은 정액이라 금액을 말함), `walk-ins`→`웍인즈`는 wok 소리
**자체 발견** — `Have a seat.`의 "해버 씨트"가 구개음화로 sheet/shit 쪽으로 들림 → 문장 교체 2건. `_stage_common.json` 「계산하기」와 미용실 계산 카드 3장이 정면 중복 → 상황을 「자르고 나서」로 통째 교체
**4라운드(코디네이터) 4건 — 전부 반영함**

1. 「자르는 중」 3번 `A little more here, please.` → **`A little more off here, please.`** / "어 리를 모어 오프 히어, 플리즈"
   `more`만으로는 "더 잘라라"와 "더 남겨라" 양쪽으로 열림. `off`가 방향을 고정
2. 「자르기 전」 4번 reply 순서·뜻 교체
   1순위 **`How much do you want off?`** "하우 머치 두유 원 오프?" / "얼마나 잘라 드릴까요?"
   2순위 `What number?` — ko를 **"이발기 몇 번으로 할까요?"** 로 (대기 번호표로 오해 방지)
3. 「자르는 중」 keywords에서 `"다됐어요"` 제거 → `"더잘라"`. (`lookup()`이 첫 매치에서 반환해 「자르고 나서」가 영영 안 뜨던 문제)
4. 탈의실 note `써 있기도` → **`쓰여 있기도`**

## 통과 판정 받은 것 — 다시 손대지 말 것

소리 표기 전수 / 중복 / 규정 단정(`volatile` 8곳) / 미국식 영어 / 8단어 / label 6자 / reply 소리표기 / 맞춤법.
탈의실 note의 `dressing room` 언급은 **어휘 설명이 아니라 행동 정보**로 통과.
옷가게 `"영수증"`, 미용실 `"팁"` 키워드는 공통 「계산하기」 폐기로 되살아남 — 그대로 둘 것.

## 기록만 (고치지 않아도 통과)

- `숏, 플리즈` / `숏 히어, 플리즈` — r이 없어 shot으로 들리나 미용실 문맥이라 오해 안 됨
- `두유 테익 워킨즈?` — 권고 표기는 `웍인즈`
- `잇처 미디엄`·`댓처 라지` — `잇서`·`댓서`가 실제 소리에 더 가까움
- 「자르기 전」 4장 중 3장 note가 "사진을 보여줘라"를 반복
- `Show me the back, please.` → 원어민은 `Can I see the back?`을 더 씀
- `Yes, tap a button.` → `Yeah, just pick one.` 쪽이 실제 말투

## 남은 판단 지점

`What number?`를 이발사가 실제로 되묻는다는 1차 근거는 미확정(가위로 자르는 salon에서는 안 나옴). `Short here, please.`는 손으로 짚는 전제가 없으면 모호. 둘 다 note로 사진·손동작을 함께 안내해 보완해 둠. 확신이 필요하면 `verifier`를 한 번 더 태울 것.
