`여기서뭐라고해요_프로젝트.zip` — 풀면 바로 돌아가는 완성된 웹앱입니다.

```
proj/
├── CLAUDE.md            ← 클로드 코드가 매번 읽는 지침
├── README.md
├── index.html
├── css/style.css
```

## 2. 준비물

**계정**: 클로드 코드는 <cite index="28-1">Pro, Max, Team, Enterprise, 또는 Console 계정이 필요합니다. 무료 플랜으로는 쓸 수 없습니다.</cite>

**설치**: <cite index="28-1">네이티브 설치 방식이 권장되며 Node.js가 필요 없습니다.</cite>

## 3. 시작하기

압축을 원하는 곳에 풀고, **그 폴더 안에서** 클로드 코드를 켭니다.

```bash
cd 여기서뭐라고해요/proj
claude
```

첫 프롬프트는 이렇게 던지세요.

```
CLAUDE.md와 docs/00_STATUS.md를 읽고, 지금 프로젝트 상태를 정리해줘.
그리고 로컬 서버로 앱을 띄워서 잘 도는지 확인해줘.
```

앱은 반드시 로컬 서버로 열어야 합니다. `index.html`을 더블클릭하면 카드 데이터를 못 읽어요.

```bash
python3 -m http.server 8000
```
→ 브라우저에서 `http://localhost:8000`

## 4. 권장 작업 순서

| 순서 | 할 일 | 프롬프트 |
|---|---|---|
| 1 | 동작 확인 | `앱 띄워서 검색·담아두기·보여주기 다 되는지 확인해줘` |
| 2 | 카드 채우기 | `@content 로 환전소 카드 만들고 @reviewer 감수받아서 cards.json에 넣어줘` |
| 3 | 사실 확인 | `@verifier 로 새로 넣은 카드 검증해줘` |
| 4 | 왕초보 점검 | `@qa 로 지금 앱 점검해줘` |
| 5 | 배포 | `GitHub Pages로 올리는 방법 알려줘` |

**2번을 반복하는 게 앞으로의 주 작업입니다.** 남은 종류는 20개 정도예요 — 환전소·옷가게·병원·은행·미용실·우체국·렌터카·버스 등.

## 5. 자주 쓰실 프롬프트

**카드 추가**
```
@content 로 "환전소" 종류를 만들어줘. 상황 4개, 각 4장.
@reviewer 감수 통과한 것만 data/cards.json에 넣고, sw.js 캐시 번호도 올려줘.
```

**명소 추가**
```
파리 명소 10곳을 @pm 이 분류해줘.
고유 카드가 필요한 곳과 관광지 공통으로 충분한 곳을 나눠서.
```

**화면 고치기**
```
@ux 로 "내 카드" 화면을 여행 단위로 묶는 안을 설계해줘.
설계 나오면 구현하고 @qa 로 점검해줘.
```

**뭔가 이상할 때**
```
@qa 관점으로 지금 화면을 써보고 막히는 곳 찾아줘. 코드는 보지 말고.
```

## 6. 배포

파일만 있으면 되는 정적 사이트라 배포가 쉽습니다.

- **GitHub Pages** — 무료. 저장소에 올리고 설정에서 켜면 끝
- **Netlify Drop** — 폴더를 웹페이지에 끌어다 놓으면 주소가 나옴. 계정도 거의 필요 없음

둘 다 **HTTPS가 필요합니다.** 서비스워커(오프라인 기능)가 HTTPS에서만 동작하거든요. 위 두 곳은 자동으로 됩니다.

배포하면 폰 브라우저에서 열고 **"홈 화면에 추가"**를 누르세요. 그때부터 진짜 앱처럼 열리고 인터넷 없이 동작합니다.

---

## 7. 꼭 지켜주실 것 3가지

**① 카드를 고쳤으면 `sw.js`의 캐시 번호를 올린다**
```js
const CACHE = 'phrase-v1';  →  'phrase-v2';
```
안 그러면 이미 설치한 사람 폰에 **옛날 카드가 그대로 남습니다.** 이거 놓치면 나중에 "왜 안 바뀌지?"로 한참 헤매게 됩니다.

**② 서버·로그인·외부 API 제안이 나오면 거절한다**
`CLAUDE.md`에 못 박아뒀지만, 대화가 길어지면 슬금슬금 나옵니다. "유지비 0원, 가입 없음"이 이 제품의 뼈대예요.

**③ 만든 에이전트가 스스로 통과시키지 않게 한다**
`@content`가 카드를 만들면 반드시 `@reviewer`를 거치게 하세요. 급하다고 건너뛰면 이 구조를 만든 의미가 없어집니다.

## 8. 마지막으로

**220장은 미국 여행 한 번이 됩니다.** 공항 내려서 입국심사 통과하고, 택시 타고 호텔 들어가서, 밥 먹고 지하철 타고 그랜드 캐니언 갔다 오는 게 다 돼요.

카드를 더 만드는 것보다 **한 사람에게라도 실제로 써보게 하는 게 먼저**입니다. `@qa`는 왕초보 흉내고, `@verifier`는 사실만 확인합니다. "이 말이 자연스러운가"와 "이 앱이 진짜 쓸 만한가"는 사람만 알아요.
