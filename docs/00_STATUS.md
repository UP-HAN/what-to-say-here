## 1. 이 프로젝트가 뭔가

**장소 기반 왕초보 영어 회화 앱** (가칭 「여기서 뭐라고 해요?」)

> 구글 지도에서 갈 곳을 검색하면, 그곳에서 실제로 쓸 문장을 왕초보도 바로 읽을 수 있는 형태로 꺼내주는 앱.

**타깃**: 해외여행 가는 성인 왕초보 (페르소나 A — 김OO, 45세, 알파벳만 읽음)
**핵심 차별점**: 입력이 '주제'가 아니라 **'장소'**. 그리고 **📱보여주기 모드**(폰을 상대에게 내미는 것)

## 3. 에이전트 구조 (요약)

| 코드 | 이름 | 임무 | 짝 |
|---|---|---|---|
| **O** | 총괄 | 일을 쪼개 나눠주고 결과를 합침 | — |
| **P** | 기획 | 범위를 정하고 자름 | — |
| **C** | 문장 | 회화 카드를 만듦 | ← R |
| **R** | 감수 | C의 영어를 현지 기준으로 깜 | → C |
| **U** | 화면 | 화면·글귀 설계 | — |
| **D** | 개발 | 코드 | ← Q |
| **Q** | 트집 | 김OO이 되어 막히는 곳 찾기 | → D |

**호출**: `@C 공항 카드 만들어줘` / `@Q 이 화면 까줘` / `@O 이번 주 정리해줘`
**철칙**: 만드는 에이전트는 자기 걸 통과시킬 수 없다. 상세는 01번 문서.

[2026-08-01] 다국어 구조로 전환 (@pm 결정) ★중대

## 7. 이것만은 잊지 말 것

1. **지표를 학습량으로 잡지 않는다.** 공부 시간·단어 수를 재는 순간 이 앱은 다른 앱과 같아진다.
   진짜 지표는 **보여주기 모드 사용률**이다.
2. **발음기호(IPA) 금지.** 한글 소리 표기만.
3. **문장은 8단어 이내.** 문법보다 통하는가가 우선.
4. **모든 문장은 실시간 생성이 아니라 미리 만들어둔 데이터가 기본.** AI는 캐시 미스 때만.
5. **Q가 하는 건 김OO 흉내일 뿐 진짜가 아니다.** 실사용자 테스트를 대체할 수 없다.
